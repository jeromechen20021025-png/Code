# Changes in Drug-Use Behaviors During the COVID-19 Pandemic

## Project Overview
This prospective longitudinal cohort study examines changes in drug-use behaviors among individuals with comorbid psychiatric disorders across three phases of the COVID-19 pandemic.

## Statistical Methods
- Descriptive statistics
- Stuart–Maxwell tests
- Ordinal mixed-effects models
- Logistic mixed-effects models
- Orthogonal contrast coding
- Repeated-measures analysis
- Data visualization

## Software
R (ordinal, lme4, and lmerTest)

## Repository Contents
Selected analytical materials supporting longitudinal modeling and visualization of changes in drug-use behaviors.
