# Benzodiazepine and Z-Drug Discontinuation and Relapse

## Project Overview
This systematic review and meta-analysis investigates the success of discontinuing long-term benzodiazepine and Z-drug use and the subsequent risk of medication resumption following successful discontinuation.

## Statistical Methods
- Random-effects meta-analysis of proportions
- Generalized linear mixed-effects models
- Between-study heterogeneity assessment
- Subgroup analyses
- Sensitivity analyses
- Forest plot visualization

## Software
R

## Repository Contents
Statistical analysis code developed for quantitative evidence synthesis and the evaluation of discontinuation and relapse outcomes.
