# Childhood Adversity, Parental Bonding, and Coping

## Project Overview
This study investigates how different configurations of parental bonding and childhood trauma are associated with adaptive and maladaptive coping strategies among Chinese young adults in a clinical sample.

## Statistical Methods
- Latent profile analysis (LPA)
- Model fit and classification assessment
- Bolck–Croon–Hagenaars (BCH) analysis
- Multiple linear regression
- Analysis of covariance (ANCOVA)
- Sensitivity analyses
- Data visualization

## Software
R and Mplus

## Repository Contents
Selected analytical scripts, Mplus syntax, and visualization code supporting the published research.
