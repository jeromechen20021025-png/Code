# Dynamic Prediction of Suicidal Ideation in Psychiatric Outpatients

## Project Overview
This naturalistic longitudinal study investigates the temporal dynamics and predictors of suicidal ideation severity among Chinese psychiatric outpatients, comprising 1,884 patients and 7,027 repeated clinical assessments.

The study integrates longitudinal statistical modeling and interpretable machine learning to examine symptom trajectories and predict future suicidal ideation severity.

## Statistical Methods
- Latent class analysis (LCA)
- Linear mixed-effects models (LMM)
- Concurrent and lagged predictor analyses
- Prediction across multiple follow-up windows
- Machine-learning model development and evaluation
- Extreme Gradient Boosting (XGBoost)
- SHapley Additive exPlanations (SHAP)
- Model performance assessment
- Data visualization

## Software
R and Python
