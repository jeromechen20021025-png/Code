# Development and Validation of Shame and Guilt Scales

## Project Overview
This mixed-methods study develops and validates psychometric instruments assessing shame and guilt among Chinese fathers of children with developmental disabilities.

## Statistical Methods
- Exploratory factor analysis (EFA)
- Confirmatory factor analysis (CFA)
- Principal axis factoring
- Parallel analysis
- Internal consistency reliability analysis
- Model fit assessment
- Psychometric validation

## Software
R (lavaan)

## Repository Contents
Selected analytical materials supporting factor analysis, reliability assessment, and psychometric evaluation.
