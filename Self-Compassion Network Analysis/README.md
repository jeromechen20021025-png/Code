# Cultural Patterns of Self-Compassion and Prosocial Behavior

## Project Overview
This cross-cultural study investigates the interrelationships among self-compassion, compassion for others, and prosocial behavior in the United States and Hong Kong using network modeling approaches.

## Statistical Methods
- Network analysis
- Bayesian network modeling
- Directed acyclic graph (DAG) estimation
- Conditional dependency analysis
- Cross-cultural comparison
- Network visualization

## Software
R

## Repository Contents
Selected analytical materials supporting network estimation, cross-cultural comparison, and visualization.

The estimated network structures represent statistical dependencies rather than established causal relationships.
