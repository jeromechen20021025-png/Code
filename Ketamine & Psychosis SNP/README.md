# Genetic Vulnerability to Psychosis in Ketamine Users

## Project Overview
This case-control study investigates associations between selected genetic variants and susceptibility to psychosis among individuals with a history of ketamine use.

## Statistical Methods
- Candidate single nucleotide polymorphism (SNP) analysis
- Genotype distribution analysis
- Genetic association testing
- Regression analysis
