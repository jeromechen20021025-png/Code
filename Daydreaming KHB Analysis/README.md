# Daydreaming, Self-Compassion, and Academic Underachievement

## Project Overview
This study investigates the relationships among daydreaming, self-compassion, and academic underachievement among high-ability students.

## Statistical Methods
- Descriptive statistics
- Regression analysis
- Karlson–Holm–Breen (KHB) decomposition
- Estimation of direct and indirect associations

## Software
Stata

## Repository Contents
Selected analytical materials supporting regression modeling and KHB decomposition.
