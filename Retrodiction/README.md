# Retrodiction: In-Group Advantages Between Europeans and Chinese

## Project Overview
This cross-cultural study investigates in-group advantages in retrodiction, examining individuals' ability to infer others' prior mental states.

The study was originally conducted as my undergraduate honors dissertation at the University of Edinburgh and subsequently developed into a peer-reviewed publication.

## Statistical Methods
- Chi-square tests
- Aligned rank transform factorial analysis
- Wilcoxon signed-rank tests
- Wilcoxon rank-sum tests
- Effect size estimation
- Benjamini–Hochberg correction
- Data visualization
